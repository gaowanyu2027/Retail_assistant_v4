## 拍摄前准备（3 分钟）

```powershell
docker compose up -d            # 起服务
docker compose exec backend curl -s http://127.0.0.1:8000/api/health/ready
```

浏览器打开 **http://127.0.0.1:8000** 登录 → 摄像头菜单 → **服务器摄像头（门店固定机位）**
（它会播放 30 秒演示视频；视频播完会显示"视频播放完毕"，所以**拍图要在播放中完成**）。

## 四张图

| 文件名 | 拍什么 | 画面里要能看到 |
|---|---|---|
| `01-monitor.png` | **实时监控页**：视频区有画面 + 检测框 | 左上状态栏"摄像头运行中"、右上 **FPS** 数值、画面里的行人框、底部统计（到访/热度） |

### 建议的提问（02 用，能同时体现数据可信度）

- 「今天客流怎么样？」
- 「1号货架的商品为什么卖不动？」
- 「有没有异常情况？」

> 若回答里出现"数据不可信 / 未采集到数据"是**正确行为**（说明可信度门禁在工作）——
> 想拍出有数据的版本，先让服务器摄像头**播一会儿**再提问。

## 拍摄要求

- **窗口宽度 1280–1600px** 即可（不要全屏 4K，图太大且文字看不清）
- PNG 格式；单张控制在 **400KB 以内**（超了用画图/在线工具压缩，或存 JPG）
- **务必检查有没有敏感信息**：右上角用户名、聊天里提到的真实店名/金额、地址栏里的内网 IP。
  要打码就用系统截图工具的马赛克，**别用涂黑整块**（看着像藏东西）
- 四张图**风格一致**（同一浏览器、同一缩放、同一主题），别一张亮一张暗
